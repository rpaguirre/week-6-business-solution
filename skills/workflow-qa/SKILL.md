# Workflow QA v1
Use before shipping changes to the five-page Everyday Access site.
Run the app.js tests: routine, verification yes/no, block, wallet/no-wallet, boundary scores, invalid input and forbidden transitions.
Check exactly five HTML pages, all five links per navigation, and every local asset reference.
Verify advertisement duration >=15 seconds and presence of captions/transcript.
Report actual outcomes; never claim browser QA or production model validation when unavailable.
